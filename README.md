# Stock Vision — Real-Time Stock Market Dashboard

![React](https://img.shields.io/badge/React-Frontend-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![API](https://img.shields.io/badge/API-Finnhub-green)

Stock Vision is a modern stock market dashboard that provides real-time market insights, live stock prices, portfolio monitoring, and interactive financial visualizations. The application enables users to track stocks, analyze market trends, and stay informed through an intuitive user interface.

**GitHub Repository:** https://github.com/RadhikaKapoor383/Stock-Vision

---

## Project Overview

Stock Vision helps users monitor financial markets by providing live stock prices, interactive charts, and portfolio tracking features. The application integrates external market APIs to deliver real-time data and market information.

The dashboard is designed with a responsive interface, making it accessible across desktop, tablet, and mobile devices.

---

## Features

* Real-time stock price updates
* Search stocks by symbol or company name
* Interactive financial charts and visualizations
* Portfolio tracking and monitoring
* Market news and summaries
